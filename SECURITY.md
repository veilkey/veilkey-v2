# Security Policy

## Supported Versions

**This repository is not supported.** It is a previous copy of VeilKey that has moved to [veilkey/veilkey-selfhosted](https://github.com/veilkey/veilkey-selfhosted). It receives **no security fixes**, and known vulnerabilities fixed in veilkey-selfhosted may still be present here.

If you run VeilKey from this repository, migrate to the latest release of [veilkey-selfhosted](https://github.com/veilkey/veilkey-selfhosted/releases).

## Reporting a Vulnerability

If you find a problem in this copy that also affects veilkey-selfhosted, report it there, privately:

1. **GitHub private vulnerability reporting** (preferred): open the **Security** tab of [veilkey-selfhosted](https://github.com/veilkey/veilkey-selfhosted) and choose **Report a vulnerability**.
2. **Email**: team@dalsoop.com

Please do **not** open a public issue or pull request for a security problem. Reports are acknowledged within 7 days, as described in the [veilkey-selfhosted security policy](https://github.com/veilkey/veilkey-selfhosted/blob/main/SECURITY.md).
